# NoteMind AI

An AI-powered personal knowledge base that lets users chat with their documents, web pages, and YouTube videos using Retrieval-Augmented Generation (RAG).

---

## Features

- Upload PDFs, TXT, DOCX, and Markdown files
- Ask questions from uploaded documents
- Web page ingestion
- YouTube transcription using Whisper AI
- Semantic search using vector embeddings
- Local LLM support using Ollama + Llama 3

---

## Tech Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- HuggingFace Embeddings
- Ollama
- Whisper AI

---

## AI Concepts Used

- Retrieval-Augmented Generation (RAG)
- Vector Databases
- Semantic Search
- NLP
- Transformer Models

---

## Project Motivation

Built as a personal AI second-brain system to organize and query scattered information efficiently.
